# 校园鲜达首页与品牌改造记录

## 问题

全新数据库迁移成功后访问首页稳定返回 HTTP 500。堆栈指向 `df_goods.views.index`，该视图不检查分类数量便固定读取索引 0～5；空数据库中分类数量为 0，因此产生 `IndexError`。

## 修改

- 首页按实际存在的有效分类动态生成展示区，支持 0～6 个分类。
- 没有分类时展示校园鲜达欢迎页，提供注册和后台入口。
- 页面标题、公共页头、登录、注册、后台标题和页脚统一为“校园鲜达”。
- 新增透明横版 Logo、站点图标、空目录插画和校园鲜达配送插画。
- 保留原数据库为空的事实，不复制往届用户、订单或商品数据。

## 手工验证

| 页面或资源 | 结果 |
|---|---|
| `/`（空数据库） | HTTP 200，显示欢迎页 |
| `/user/login/` | HTTP 200，显示校园鲜达 Logo |
| `/user/register/` | HTTP 200，协议名称已更新 |
| `/admin/login/` | 后台标题更新为校园鲜达 |
| 品牌图片资源 | HTTP 200，PNG 透明通道有效 |

这项修改用于建立可演示的空数据库起点，不属于模块一 AI 生成测试用例或自动化测试。
