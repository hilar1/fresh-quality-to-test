# 成员 B：商品与浏览模块需求规格

## 1. 基本信息

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 校园鲜达 |
| 负责人 | 成员 B |
| 需求基线 | `demo-v0.3`（提交 `84aa763`） |
| 模块范围 | 商品分类、首页展示、商品列表、商品详情、搜索、浏览历史、演示数据、质量度量 |
| 上游依赖 | 成员 A 提供登录用户和用户中心；项目公共环境可正常启动 |
| 下游依赖 | 成员 C 使用有效商品、价格和库存完成购物车及订单流程 |

## 2. 目标与边界

本模块为用户提供从首页发现商品、按分类浏览、排序、搜索、查看详情到保存最近浏览记录的完整路径，并提供可重复加载的课程演示数据和客观质量度量。

本模块不负责用户认证、收货地址、购物车结算、订单生成、真实支付和物流。

## 3. 参与者与前置条件

- 游客：可浏览和搜索有效商品，不保存账户浏览历史。
- 登录用户：具备游客能力，并保存个人最近浏览记录。
- 管理员或数据维护者：维护分类、商品、图片、价格和库存演示数据。
- 系统启动后数据库结构完整，静态资源能够访问；没有商品数据时页面仍可正常显示空状态。

## 5. 业务规则

1. “有效分类”指 `isDelete=False` 的分类；“有效商品”指 `isDelete=False` 且所属分类有效的商品。
2. 最新商品按商品记录创建顺序从新到旧排列；热门商品按浏览次数从高到低排列。
3. 商品价格参与计算时必须使用十进制金额，页面统一显示两位小数。
4. 浏览历史属于个人数据，任何查询和更新都必须同时使用当前登录用户作为条件。
5. 推荐内容必须遵守商品有效性规则，不能通过推荐入口绕过下架状态。

## 6. 异常与质量要求

- 首页、分类列表、搜索和详情页在本地课程演示环境下应保持可正常操作，常规请求不应出现明显卡顿。
- 用户输入应经过服务器端校验和安全转义，错误输入不得导致服务器错误或泄露调试信息。
- 页面应沿用“校园鲜达”的名称、标志和绿色视觉风格，在常见桌面浏览器中保持主要内容可读。
- 数据加载说明、数据来源和图片来源应记录在仓库内，方便其他成员复现。
