# 校园鲜达质量改进项目

本仓库用于软件测试与质量保证课程实践。被测系统以 DailyFresh Django 生鲜商城的代码快照为起点，三名成员将在清晰标注来源的基础上重新完成需求分析、测试设计、测试实现、缺陷验证和质量改进。

## 当前状态

当前版本是待测系统基线，只用于保留改造前状态。原参考包的虚拟环境绑定了其他电脑上的 Python 3.8，依赖说明也存在 Django 版本不一致，因此本基线尚未声明可在新环境运行。环境迁移应作为后续独立提交完成，并保留改造前后的验证证据。

模块一的测试用例和自动化测试不会从往届材料复制，也不会由 AI 生成。

## 业务范围

- 用户、登录和收货信息
- 商品、搜索和浏览历史
- 购物车、订单和库存

## 目录

- `apps/`：商城业务模块
- `daily_fresh_demo/`：Django 项目配置
- `templates/`：页面模板
- `static/`：静态资源
- `sql/`：原参考项目附带的数据库结构说明
- `docs/`：项目设计、需求、缺陷、报告和 AI 过程记录

## 协作要求

三名成员使用各自的 GitHub 账号提交实际完成的工作。每名成员负责一个业务域，并在该业务域中完成需求、人工测试设计、自动化实现、缺陷闭环和文档。提交信息应描述真实变更，不补造或代替他人提交。

## 后续里程碑

1. `baseline-v0.1`：清理后的待测系统基线。
2. 环境迁移：建立统一且可复现的 Python 和 Django 环境。
3. `module1-final`：完成基础测试、缺陷修复与回归。
4. 模块二：在模块一版本上开展 AI 辅助测试对照实验。
